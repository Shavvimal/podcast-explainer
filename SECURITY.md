# Security

## Reporting

Report vulnerabilities privately through
[GitHub's security advisories](https://github.com/Shavvimal/podcast-explainer/security/advisories/new).
Do not open a public issue for a security problem. You should hear back within a week.

## What this skill touches

- **A Gemini API key.** `scripts/tts.py` and `scripts/preflight.py` read `GEMINI_API_KEY` from the
  environment, else from a dotenv file (`PODCAST_EXPLAINER_ENV_FILE`, else
  `$XDG_CONFIG_HOME/podcast-explainer/env`, else `~/.config/podcast-explainer/env`), parsed in code by
  `pe_common.load_api_key`. The key is validated before any header is built, registered for redaction,
  and never printed, logged or written to a file. Every log line, error, report and cache file passes
  through `pe_common.redact`, which also strips any Google-shaped key or `key=` query value it did not
  know about. `preflight.py` reports only "present" or "missing". The skill text tells the agent never to
  `cat`, echo or ask the user to paste the key.
- **The network.** Only `tts.py` and `preflight.py` make network calls, and only to
  `generativelanguage.googleapis.com` (Gemini Developer API, `generateContent` and the model list).
  `align.mjs` can download whisper.cpp and its model on first use, through `@remotion/install-whisper-cpp`.
  `npm install` in the Remotion template fetches its pinned dependencies. There are no other network calls.
- **Files.** Every script writes inside the workspace folder (`explainers/` by default) and the Remotion
  project. Paths that come from the command line are checked with `pe_common.inside`, so a slug or an
  output path cannot escape the workspace. SVG that reaches the renderer is sanitised
  (`templates/remotion/src/svgSanitize.ts`).
- **Subprocesses.** `ffmpeg`, `ffprobe`, `node`, `npx remotion` and (for the free `--scratch` voice on
  macOS) `say` run with argument lists, never a shell string.
- **Third-party agents.** The QC step asks a separate agent to judge the video and a blind agent to
  restate the concept. Both read files inside the workspace only; the briefs they get are generated by
  `qc.py`. Treat their output as untrusted text.

## Not in scope

Prompt injection through a source document is a known risk of any agent that reads documents. The
skill mitigates it by requiring every number to trace to `facts.json` with a verbatim quote, but a
hostile source can still shape the script. Review the outline at gate 1.

## Supported versions

The latest release on `main`. Fixes land as new releases; there are no backports.
