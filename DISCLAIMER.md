The skill calls the paid Gemini Developer API for text-to-speech. Every per-turn call is billed, and a
retry is billed again. The reference costs in `skills/podcast-explainer-video/references/gemini-tts.md`
were read from Google's pricing page on the date stated there and can change. You are responsible for the
bills your API key incurs. The skill stops at three human gates before any paid call and offers a free
`--scratch` voice for drafts, but it cannot prevent a run you approved from costing money.
